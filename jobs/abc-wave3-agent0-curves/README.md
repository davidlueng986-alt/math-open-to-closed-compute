# ABC Wave 3 fixed escape curves

Certified, database-independent Sage/mwrank checks of the fixed genus-two obstruction's elliptic quotient, rank, torsion and local descent obstruction. This verifies a finite complete elliptic computation supporting the written root-escape proof. It does not establish ROOT-BOUND or abc.

Run: `bash run.sh 0 1 out` inside the pinned Sage image.

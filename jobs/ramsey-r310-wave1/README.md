# Ramsey R(3,10) — independent replay and bounded construction search

Original target: a triangle-free simple graph of order 40 with independence number at most 9, or a proof none exists. Public inputs only: Exoo 39-vertex graph from https://github.com/daniel-munro/leaps-in-bounds/blob/main/certificates/ramsey/ramsey-3-10-lower-40.g6 ; Kalbfleisch 35-vertex graph from Brendan McKay's collection https://users.cecs.anu.edu.au/~bdm/data/r39_35.g6 (CC BY 4.0). Degree-4 exclusion relies on published uniqueness of the (3,9,35) graph (Goedgebeur–Radziszowski), not on reproducing that classification. Each search preserves triangle-freeness and maximum degree 9, edits arbitrary old edges to repair sampled independent 10-sets, refills admissible edges, uses different random seeds/temperatures, and maintains exact counts via edge-flip deltas. Python independently recomputes all counts. A nonzero score is not an impossibility proof. Each search shard has a 900-second algorithm deadline and 25-minute job cap; no schedule or paid resources. The path-scoped push trigger launches the initial batch once when launch.txt changes. Future manual dispatch is optional.

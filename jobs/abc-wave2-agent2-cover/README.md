# ABC Wave 2 Agent 2 — orbit coverage verifier

This finite deterministic job verifies the image/inverse classification of the primitive odd-c squaring map, rooted descent, the exact even-c radical transform, fixed rational quality implications and rational algebra for a conditional global composition. It does not prove either open uniform estimate or abc.

Run `bash jobs/abc-wave2-agent2-cover/run.sh 0 1 OUT` from the compute repository. Python 3 standard library is sufficient; one shard is required. Output: `result.json` and `certificates.json`. The source hash and certificate hash are recorded by the job itself; GitHub provenance is recorded from the runner environment.

Research report: `research/ABC/wave2_agent2/REPORT.md` in `davidlueng986-alt/math-open-to-closed`.

Local c<=600 run: 54,750 primitive triples, 36,468 odd-c classifications and descents, 58 image triples, 18,282 even-c radical transforms, 31,005 rational composition cases. The finite domain does not certify an infinite or uniform bound.

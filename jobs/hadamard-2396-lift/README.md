# A less symmetric search for the fourth Hadamard component

Tests 4,096 seeded supports for the trivial Walsh component at order 2396. Each mixed block has one central spike and a support symmetric under reversal away from zero. The three symmetric supports are disjoint and have 18, 18 and 22 opposite pairs. The fourth block has a positive central entry and 32 freely placed nonzero entries. These sizes come from rounding the proportions in the published order-668 core. They are experimental choices.

A shift with no spike neighbor must have an even total overlap. For a reflection-symmetric set the parity of the overlap at shift s is its membership at s/2, by pairing each summand with its reflection. The template chooses the uncovered opposite pairs to enforce this identity using the actual fourth support. Every other shift has two spike neighbors. Thus the binary equations from the companion job test every shift modulo 16 exactly. Each admissible point is tested against the exact sum-of-squares identity 599. The resulting signings are scored by the sum of squares of the 74 ordinary integer autocorrelations. A positive score is a partial certificate only. The merge recomputes all 149 shift values directly from each winning signing.

For each of the 4,096 support seeds, an inconsistent congruence or a failed necessary row-norm test proves rejection. For every remaining support, Gray-code enumeration covers the whole affine sign space. The summary records its dimension, the number of exact row-norm hits, the number satisfying every shift modulo 32, and the number with exactly zero autocorrelation. If any modulo-32 example is found, the merge verifies its ordinary integer correlations directly. The experiment covers this finite set of supports. Reproduce with the sharded-run workflow or bash jobs/hadamard-2396-lift/run.sh 0 1 /tmp/lift/shard-0 followed by python3 jobs/hadamard-2396-lift/merge.py /tmp/lift /tmp/lift-summary.

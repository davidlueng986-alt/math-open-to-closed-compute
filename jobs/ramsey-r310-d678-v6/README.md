# D678 v6 — exact profile certificates and nested Ramsey bounds

Existing v5 bands are preserved. Let W be saturated, alpha<=9, triangle-free, |V|=40. For any vertex v of degree k, A=N(v), H=V-(A+v), h=39-k. Every H vertex has an A-neighbor. The vertices with exactly one A-neighbor a form an independent set together with A-{a}, so at most 10-k of them per a. Thus the cross-edge count is at least 2h-k(10-k) and at most 8k. For k=5 this is 43>40, proving MIN6 directly without any D5 computational dependency. For k=6, the cross count is at least 42 and sum of neighbor degrees >=48; e(H)>=118 (published), hence m>=166. Also 2e(H)<=9h-cross implies e(H)<=floor((7h+k(10-k))/2). Thus four old low-edge bands D6-N6-B0, D6-N7-B0 (also independently DRAT certified), D7-N6-B0, D8-N6-B0 are mathematically impossible.

## Exact profile screen

For each profile n=(n6,n7,n8,n9), list possible local types (k,a) where a records numbers of neighbors of each degree. Filter by availability, total degree, dual edge bounds, singleton lower bound above and codegree constraints. A nonadjacent pair of degrees i,j has 1<=codeg<=i+j-11, by saturation and R(3,8)=28. Each vertex of degree k has cross-count sum_j j*a_j-k, at most sum over its nonneighbors of min(k,j,k+j-11); those with cap1 must be singleton vertices.

Let x_(k,a) count vertices of each type. Nonnegative x, class totals n_k, reciprocity of edge counts between classes. For class pair i,j, count length-two paths by center: sum x a_i a_j for distinct classes, sum x a_i(a_i-1) for same class (ordered pairs). Adjacent pairs have no common neighbor; for every nonadjacent pair the count is between 1 and i+j-11. Hence linear inequalities A_ub x<=b_ub and equalities A_eq x=b_eq. An integer multiplier y, nonnegative on inequality rows, with y A>=0 for every type column and y b<0 proves no such x. HiGHS generates candidates only; the pure integer checker verifies all columns, row signs and contradiction. No numerical infeasibility is accepted without exact witness. The local run excluded 388 of 931, leaving 543 (333 with n6>0). Exact branch filter enumerates X,Y degree multisets as in v5, demands both root types be allowed, and preserves every original band boundary. Counts are necessary profiles, NOT graphs. ## Nested dual pruning

For H=G-N[v], alpha(H)<=8. If x has internal degree r, then H-N_H[x] has n_H-1-r vertices and alpha<=7. Triangle-freeness gives e(H-N_H[x])=e(H)-sum_(y in N_H(x)) deg_H(y). Hence sum_(y in N_H(x))(8-deg_H(y)) >= e(3,8,n_H-1-r)+8r-e(H). Encode exact e(H) binary selector, degree thresholds and conditional deficit constraints in both duals. Exact minima for n=21..27: 35,42,49,56,65,73,85. For nonadjacent x,y in H, common nonneighbors <=22 by R(3,7)=23, thus deg_H(x)+deg_H(y)-codeg_H(x,y)>=|H|-24. Use this for low internal degrees in large duals, guarded by nonadjacency. All constraints are necessary, subject to independent mathematical/CNF audit.

# 九組重配欄對的索引 18 容量

八組與九組精確 Sylvester 欄對的兩個配置共享物理折疊，以及每個下部投影的索引模八值。在固定 988 上部下，第一 Sylvester 複本的保留索引 18 提供新的精確限制。兩組配置在該索引的五維模八標籤都是 $(2,0,4,6,6)$，而持此標籤的 63 條上部欄，其第二座標至少為 $-32$。[兩個配置與精確欄對](EXTERIOR_REINDEXED_ANCHORS.md)

保留所有實體行重量及第二條新欄的總負號數。若五條折疊都固定，索引 18 的帶配對符號投影在第二座標至多為 $-48$。若只固定第二條折疊，放開其他四條，容量仍至多為 $-40$。因此要精確配對索引 18，必須改變第二條折疊或索引 18 的模八標籤。這個限制容許改變兩半各自的欄重量、省略投影和新欄 Gram。[標準函式庫驗算](exterior_reindexed_pivot.py)

若只改索引標籤，固定第二條折疊和總負號數仍使第二座標等於零模八。滿足第二座標至多 $-40$ 的上部欄有以下 28 條。其餘精確相容條件仍須求解。

| 模八標籤 | 上部欄數 |
| ---: | ---: |
| $(2,0,0,2,6)$ | 5 |
| $(2,0,0,6,2)$ | 3 |
| $(2,0,4,2,2)$ | 4 |
| $(6,0,0,2,2)$ | 3 |
| $(6,0,0,6,6)$ | 1 |
| $(6,0,4,2,6)$ | 5 |
| $(6,0,4,6,2)$ | 7 |

## 改變第二條折疊的必要條件

記第二條新欄在每個實體行對的兩個負號位元為 $x_r,y_r$，總負號數為 $W$，Paley 欄 18 在該位置的符號為 $h_r$。第一複本投影為 $\sum_r h_r(2-2(x_r+y_r))$。固定每個實體行的重量後，第二折疊 $s_r=x_r\oplus y_r$ 決定當地可以選擇的位元對。給總重量一個係數 $\mu$，對每個行對最大化
$$h_r(2-2(x_r+y_r))-\mu(x_r+y_r).$$
把最大值求和並加回 $\mu W$，得到有效容量上界。整理同號行對的增益並依總重量取最高項，可精確求出固定折疊的標量容量。

只固定第二條折疊時，取 $\mu=-2$ 恰給回參考容量 $-40$。翻轉一個折疊位元的容量變化在 172 個行對是 $+4$，在 128 個行對是 $-4$，另 300 個行對為零。保留索引 18 的原模八標籤至少需要容量達到 $-32$。因此改動的支援中，落在 172 個正增益位置的數目，必須比落在 128 個負增益位置的數目至少多二。這是一項必要條件，驗算器可從公開九組配置的行遮罩重建每項係數。[逐行整數驗算](exterior_reindexed_pivot.py)

```sh
python3 -B jobs/hadamard-all-orders/exterior_reindexed_pivot.py
```

## 保留第二折疊的實體重配

已取得一組實體下部，保留九組配置的全部 600 個第二折疊位元，並把索引 18 的模八標籤改為 $(2,0,0,6,2)$。三組原先指定的完整 Sylvester 欄對與新的索引 18 欄對都精確相消，索引從零開始。

| 下部第一複本 | 下部第二複本 | 上部第一配對欄 | 上部第二配對欄 |
| ---: | ---: | ---: | ---: |
| 12 | 612 | 506 | 313 |
| 14 | 614 | 128 | 277 |
| 18 | 618 | 588 | 77 |
| 313 | 913 | 592 | 577 |

下部 18 和 618 的帶配對符號投影分別是 $(10,-48,16,6,18)$ 和 $(-6,16,-36,46,-18)$。相對九組配置，實體行遮罩改變 555 行，折疊變動落在 419 個行對，第二條新欄改變八個實體符號，另有 1,022 條索引模八投影改變。原第八精確省略因數的 35 項投影、所有實體行重量、每半的總欄重量、新欄 Gram 和省略 Gram 全部精確保留。原九組欄對的 18 個投影仍各自保留第二座標的精確值，表列四組欄對則保留完整五維配對。[實體行遮罩及配對](exterior_reindexed_pivot_witness.json)

先固定第二條折疊，選擇第二條新欄的符號，使其精確投影符合指定欄對。以這些符號固定後，在行重量允許的範圍內選擇另四條新欄，使指定投影、原省略投影與兩項 Gram 都成立。之後以保持第二欄符號的整數互抵行交換，重配模八多重集。交換時同一半的兩行具有同重量和同第二欄符號，且所選交換對指定保留欄及省略欄的投影變化逐項相加為零。

移除這八條已精確相消的投影後，其餘模八多重集仍完全一致。固定這四組指定欄對時，模 8、16、32、64 及整數精確的配對數依序為 1,193、906、282、26、15。指定模十六向量 $(6,4,12,14,14)$ 的重數是三。完整 1,193 組精確相消仍待取得。[實體整數重跑](exterior_reindexed_pivot.py)

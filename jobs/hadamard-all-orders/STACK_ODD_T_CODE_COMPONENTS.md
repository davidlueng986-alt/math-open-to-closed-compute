# 交叉內積碼排除六種固定疊接的張量輔助矩陣

在六個經驗算的 2396 階疊接配對中，若可完整補欄，輔助 1200 階 Hadamard 不能由兩個較小 Hadamard 的非平凡張量積經行欄重排、變號而成。這項排除適用於這六種固定的舊欄配對。它保留選擇其他配對或其他輔助矩陣的可能。[四通道見證](STACK_1197_FOUR_CHANNELS.md) · [兩個各自精確的配對](STACK_1198_MARGINALS.md)

## 輔助矩陣刪除四行後的碼由交叉內積決定

對任意奇數 \(t>1\)，令 \(n=2(t-1)\)、\(m=2(t+1)\)、\(N=n+m\)。固定舊的疊接 \([A;B]\) 及完整下方來源 \(M=[B\ D]\)。若可完整延伸，存在輔助 \(T=[X;F]\) 和四維邊界矩陣 \(K\)。模奇質數 \(p\) 取 \(p\mid m\)、\(p^2\nmid m\)，則 \(n,N\) 都可逆，且

\[
 \operatorname{im}_{p}(S T)=\ker_{p}M=\operatorname{im}_{p} M^{\mathsf T},
 \qquad S=\operatorname{diag}(-A^{\mathsf T},K).
\]

第一個包含關係來自輔助整數同餘。對任一階數 \(m\) 的 Hadamard \(L\)，若整數向量滿足 \(Lw=py\)，則 \(L^{\mathsf T}y=(m/p)w\)。因此在模 \(p\)，\(\ker L=\operatorname{im} L^{\mathsf T}\)，而轉置保留秩，兩者維度都是 \(m/2\)。這證明上式的等號。[輔助矩陣等價條件](STACK_ODD_T_AUXILIARY.md)

現在令 \(\pi\) 刪除最後四個座標。用 \((-A^{\mathsf T})^{-1}=-A/n\) 得到

\[
 \pi\operatorname{im}_{p}T
  = \operatorname{im}_{p}\bigl((-A/n) B^{\mathsf T}\bigr)
  = \operatorname{im}_{p}(A B^{\mathsf T}).
\]

這個碼只需用現有舊欄重建。它不依賴選了哪個邊界 \(K\)，也不依賴新增的符號欄。

## 用系統基底驗證座標不可分拆

把碼的基底化成在主元座標為單位矩陣的形式。在每個基底向量的主元和它其餘非零座標之間連邊。若碼為兩個各限制在互不相交座標集上的直和，任何基底向量也必須支撐在其中一側。否則，把它投影到不含其主元的那側，仍屬該碼，但所有主元座標為零，只能是零向量。因此連通的支撐圖排除了該種直和分拆。反過來，每個連通分量中的基底向量都只支撐在該分量，所以分量直接給出分拆。

若 \(T\) 來自非平凡張量 \(R\otimes H\)，因 \(p\) 在 \(m\) 的指數為一，可以交換兩因子使 \(R\) 的階數和 \(p\) 互質。\(R\) 在模 \(p\) 可逆，因此張量的像是 \(\operatorname{im}_{p} H\) 在互斥座標上的多個複本。行欄重排和變號保留這個分拆。\(H\) 的階數是被奇質數 \(p\) 整除的 Hadamard 階數，必為至少 12。刪除四個座標後，每個複本仍非零，因為其像含有全支撐的符號欄。若上式的交叉內積碼連通，這便矛盾。

在 2396 階，取 \(p=3\)。四通道首欄的原配對、四通道平方殘差 1,920 的配對，以及雙通道原相位和射影相位各自的兩個邊際配對，重跑後均得秩 600、長度 1,196 的單一連通分量。重跑器直接以整數內積形成 \(AB^{\mathsf T}\) 再做三元消去。對照使用 \(H_4\otimes H_{12}\)，每個複本刪除一個位置後，確實得四個大小 11 的分量及秩 24。[整數重跑](stack_odd_t_code_components.py)

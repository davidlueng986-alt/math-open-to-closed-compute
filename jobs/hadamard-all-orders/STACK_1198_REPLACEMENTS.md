# 第 1,198 欄的三次支撐置換排除

由反對稱通道已精確、對稱通道平方誤差為 2,112 的證書出發，固定兩部來源、首條新增欄、上部與下方對稱通道的參考欄，以及下方反對稱通道的參考符號。上部有 32 個翻號位置，下方兩通道分別有 34 個孔位與 34 個支撐位置。容許在同一組內把任一選中位置換成任一未選中位置，也容許舊欄重新配對與變號。在三組合計至多三次置換的範圍內，沒有精確第 1,198 欄。[起點見證](STACK_1198_CHANNELS.md) · [Python 整數重跑](stack_1198_replacements.py)

## 如何覆蓋全部鄰域

在舊欄上量得首條與第二條新增欄的內積 \((a,b)\)。可重配與變號的精確條件，是上下兩部的共同變號等價類重數一致。當 \(a\ne0\) 時將類寫成 \((|a|,\operatorname{sgn}(a)b)\)，當 \(a=0\) 時寫成 \((0,|b|)\)。因此每個正的首內積大小組都必須有相同的定向第二內積總和。

取大小為 4、8、…、36 的九組。兩條首參考欄位於 1,132 組，兩條第二參考欄位於 0 組，四條省略欄在下部移除。其餘第二內積是支撐上對應符號的帶權和，因參考欄與同源其他欄正交。下部獨立重新對齊兩通道時，只須保持首欄的對稱及反對稱座標分類。這種對齊同時作用於候選下部字和來源欄，故不改變通道內積。九個定向總和差除以四得到整數向量，每次置換對它造成的改變與其他置換相加。

三組共有 75,736 次單一置換，產生 75,733 個不同九維向量。所需的位移和為 \((4,-7,-11,5,3,-2,4,-1,0)\)。C++ 將九維向量編成帶符號的混合進位整數。每一位的進位基數大於目標和至多三個位移相減後該位的絕對值。因此逐位取模可證，整數相等恰好對應各座標相等。排序後雙指標窮盡一、二、三次位移和，包括同類位移重複使用。沒有一或二次的解，三次有 3,734 組位移向量。[完整枚舉](stack_1198_replacements.cpp)

展開位移回原位置後，3,665 組使用的六個位置互不重複。下方通道每一類的孔位和支撐必須可一一對齊，通過者有 3,661 組。當中 3,272 組與首新增欄的上下合計內積為零，其餘可排除。最後直接比較這 3,272 組的完整上下定向重數，無一相同。這項排除允許首新增欄的上下內積分別非零，只要求兩者相消，也涵蓋所有相容的舊欄配對。改變參考欄或走出此三次鄰域仍是可行的研究方向。

## 變更省略投影方向須至少十八次置換

起點四個省略半內積按索引 177、573、1123、48 排列為 \((18,4,34,-30)\)。固定首新增欄時，所需平方長度與相容內積給出共 46 個帶方向的候選。一次對稱支撐置換只會改動三個對稱半內積，每個變化絕對值至多二。一次反對稱支撐置換只會改動另一個半內積，也至多二。對任意其他方向，用三個對稱座標的最大半差向上取整，加上反對稱座標的半差向上取整，所得最小值是 18。這個下界適用於任意匹配，在同一參考欄與支撐模型內排除了用少量置換切換省略方向的做法。[46 個方向的枚舉](stack_1198.py)

c++ -O3 -std=c++20 -Wall -Wextra -Werror -fopenmp jobs/hadamard-all-orders/stack_1198_replacements.cpp -o /tmp/hadamard-stack-replacements

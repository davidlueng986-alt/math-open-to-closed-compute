# Paley 四邊框的單組特徵三條件與九個投影跡

從 `border4_2396_paley_reselected_heads.FIXTURES[2]` 取首字 \(U,V\)，在保留尾字 \(W\) 的模 13、模 23 整數邊際的條件下，找到四組實體符號。將所有正負半部一同作循環座標置換後，四組都達成 `BORDER4_2396_PALEY_RELATIVE_TRACE_GATE.md` 指定的九個係數軌道同餘，以及一組本原特徵三互反因子條件。四組分別涵蓋因子組 0 至 3，並各自維持正半部精確、負半部兩個整數商精確、四列總和 \((0,2,0,0)\) 以及 597 個原始非零位移均模 8 為零。

以 \(C_A\) 表示循環自相關，令 \(E=C_U+C_V+2C_W-1196\delta_0\)。反射軸為 188，尾字差 \(D\) 由兩個符號相同的反射點同時翻號組成，因此 \(D^*=z^{-188}D\)。在指定本原因子的剩餘域內，代入 \(W+D\) 把自相關條件化成

\[
 E+2(W^*+z^{-188}W)D+2z^{-188}D^2=0.
\]

先解這個二次式，再於整數邊際圖上合併交替閉路。每條閉路保留兩組整數邊際。各閉路使用互不相交的翻號位置，於指定剩餘域的 \(D\) 值及模 2 軌道係數可以加總。模 2 線性來自把翻號量寫成 \(D=2d\)。在循環群環中，\(W\equiv J\pmod2\)，其中 \(J=\sum_{j=0}^{298}z^j\)。因此 \(W^*d+Wd^*\) 每一個係數為偶數。模 16 以 \(\Delta E/8\) 記錄翻號效果時，任兩個變動 \(D_1=2d_1\)、\(D_2=2d_2\) 的交叉差為 \(d_1d_2^*+d_2d_1^*\)。兩個 \(d\) 皆滿足同一反射關係，所以交叉差等於 \(2z^{-188}d_1d_2\)。九個軌道在這個共同反射分支因此可以加入同一次配對搜尋。

座標置換的定義為 \(a'_j=a_{mj\bmod299}\)。它作用於兩個半部的全部八列，並使 \(E'_j=E_{mj\bmod299}\)。程式在置換後的座標直接重建四個 598 項符號字，重算兩個整數商及完整原始自相關，並在相對跡文件原用的軌道代表 \((3,7,10,11,16,22,23,25,48)\) 驗證 \(E'_d+E'_{139d}+E'_{185d}\equiv0\pmod{16}\)。

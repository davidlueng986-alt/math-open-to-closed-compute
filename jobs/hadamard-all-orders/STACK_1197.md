# 2396 階的 1197 條精確正交符號欄

已構造一個 \(2396\times1197\) 符號陣，全部 715,806 個不同欄對的內積均為整數零。因此 \(r(2396)\ge1197\)，比先前 1196 欄的疊接證書多一欄。這個證書距已知的七欄完成門檻 2389 欄仍有 1192 欄。[精確重跑](stack_1197.py)

## 用絕對內積的多重集配對

設 \(A,B\) 是階數 \(a,b\) 的 Hadamard 方陣，\(a\le b\)。把 \(A\) 的每一欄和 \(B\) 的不同欄垂直疊接，可得 \(a\) 個互相正交的符號欄。給定兩個符號向量 \(u\in\{\pm1\}^a\)、\(v\in\{\pm1\}^b\)，要再加入 \((u,v)\)，充要條件是 \(A^{\mathsf T}u\) 各分量的絕對值多重集包含於 \(B^{\mathsf T}v\) 的相應多重集。充分性由逐欄配對同一絕對值，再把下半欄變號以相消取得。必要性直接來自新欄和每一條疊接欄正交。這個判準容許重排及變號下半欄。

若配對成功，令 \(B_0\) 為省略的下半欄。由 Parseval 等式，

\[
 \|B_0^{\mathsf T}v\|^2=b^2-a^2.
\]

這把絕對內積的配對搜尋限制到省略欄的少量平方和。本例取 \(a=1196\)、\(b=1200\)，省略的四個絕對內積為 \(8,36,60,68\)，平方和是 \(9584\)。

## 具體證書

上半部採用長度 299 的 Goethals–Seidel 方陣，下半部採用 Paley \(H(600)\) 的 Sylvester 加倍。兩個來源各自逐行變號，把首欄正規化為全正。候選向量 \(u,v\) 從這個全正欄出發，分別反轉明列的 32 個上半部位置和 34 個下半部位置。這兩組位置與省略欄皆採從 0 起算。兩個首欄的候選內積同為 \(1132\)。省略下部索引 \(177,573,1123,48\) 後，剩餘 1196 個絕對內積與上部完全相同。[來源方陣](verify.py) · [符號位置與配對](stack_1197.py)

## 再加一欄的精確篩選

在保留全部 1196 條來源疊接欄時，任何新欄的上半部，與任一帶符號的上部來源欄至少相差 28 格。這項下界容許任意兩個 Hadamard 來源、任意四條下部省略欄及任意配對。若上半部與某帶符號欄相差 \(r\le28\) 格，該內積的絕對值是 \(1196-2r\)，因此下部須與配對的帶符號欄相差 \(r+2\) 格。每條下部省略欄與所配對的來源欄正交，所以它對新下部的內積除以二後，絕對值至多 \(r+2\)，且與 \(r+2\) 同奇偶。四個這樣的數的平方和必為 \(9584/4=2396\)。整數枚舉排除 \(r\le27\)。在 \(r=28\) 時，絕對值只容許 \((6,26,28,30)\)、\((12,26,26,30)\)、\((14,20,30,30)\)。

一般地，考慮在全部 1196 條來源疊接欄之外加入數條互相正交的新欄。新欄分成上部 \(X\) 和下部 \(Y\)，四條下部省略來源欄組成 \(D\)，記 \(\beta=D^{\mathsf T}Y\)、\(Z=\beta/2\)。把每條舊欄對所有新欄的投影向量在兩部相消，再用 \(X^{\mathsf T}X+Y^{\mathsf T}Y=2396I\)，得到
\[
 Z^{\mathsf T}Z=599(1200I-X^{\mathsf T}X).
\]
因此每個 \(Z\) 欄的平方長度為 2396，任兩條新上部欄的內積絕對值至多 4。新下部與全部來源欄的內積模四相同；上部亦然。舊欄正交要求兩個模四值相消，所以 \(Z\) 欄的四項奇偶相同，且等於新上部欄負號數的奇偶。

本證書首條新欄的 \(Z\) 各項絕對值為 \((4,18,30,34)\)。可固定省略欄符號，令這四項全正。第二條新欄若為偶類，與首欄的上部內積可為 \(0,\pm4\)，所以兩個 \(Z\) 欄的內積絕對值只可能為 0 或 2396。第二條若為奇類，上部內積只能為 \(\pm2\)，所以兩個 \(Z\) 欄的內積絕對值只能為 1198。枚舉四個整數的平方和後，第二條欄的省略投影只餘 **七個偶類方向與十六個奇類方向**，每對相反向量視為一個方向。這項篩選也適用於保留首條新欄及同一省略組、重新配對舊欄的搜尋。

## 保留全部來源欄時的完整矩陣

若這條路線完成了 2396 階 Hadamard，則 \(Y\) 恰有 1200 欄。乘下部行 Gram 左右以 \(D^{\mathsf T},D\)，用四條省略欄與所有下部舊欄正交，得 \(ZZ^{\mathsf T}=599\cdot1200I_4\)。將 \(Z\) 各欄除以 \(2\sqrt{599}\)，得到單位方向的緊框架，其外積和是 \(300I_4\)。

同一奇偶類的不同方向互相正交。異類方向的內積絕對值恆為 \(1/2\)。若只有偶類，必有四個方向，每個出現 300 次。取其中一個方向，把該組的欄逐一變號使 \(Z\) 相同。該組上部兩欄間內積為 \(-4\)，所以 300 條上部欄的和為零。由舊欄相消，下部欄的和必在 \(D\) 的張成空間，且等於 \(D\beta_j/4\)，其中 \(\beta_j\) 是該組共同投影。因偶類的 \(\beta_j/4\) 是整數向量且平方長度為 599，每個下部行和都是奇數。300 個符號之和卻必為偶數。

本證書已含一條偶類新欄，所以完整延伸必須同時使用兩類。令兩類框架算子分別為 \(P,Q\)，滿足 \(P+Q=300I\)。各方向是其自身類別算子的特徵向量，特徵值為該方向出現次數。對另一類算子，特徵值是 300 減去該次數。異類方向互不垂直，故它們對 \(P\) 的特徵值相同。於是每個偶類方向都出現同一個正整數次數 \(a\)，每個奇類方向都出現 \(300-a>0\) 次。兩類張成相同空間，合起來橫跨四維，故各有四個方向。上面的有限枚舉留下恰四對「四偶、四奇」方向框架，仍須實現為同一個符號矩陣。[整數篩選](stack_1197.py)

# 第八組精確因數的固定行對障礙

固定 [988 配置](EXTERIOR_MOD16_INVARIANT.md) 的上部，並從[第八組精確因數的實體下部](exterior_exact_factor_witnesses.json) 出發。保持下部每個 Sylvester 行對的遮罩異或、兩行各自的重量及下述各組遮罩重數時，即使重配全部保留欄，也無法使全部新舊內積模十六相消。在這個範圍內，上部只要有一種餘數向量的重數等式，就會導出矛盾。[獨立整數重跑](exterior_folded_obstruction.py)

## 容許的下部排列

令一個實體行對的負號遮罩為 $(x_{0,r},x_{1,r})$，並記 $s_r=x_{0,r}\oplus x_{1,r}$。把具有相同
$$\bigl(s_r,\operatorname{wt}(x_{0,r}),\operatorname{wt}(x_{1,r})\bigr)$$
的行對放在同一組，在組內任意重排原有第一半遮罩。第二半遮罩由 $s_r$ 唯一指定。指定行所在的行對固定。六條非恆定省略欄的精確投影 $\beta$ 也固定。此模型容許跨越不同省略符號型態重排實體行。

每組的遮罩重數固定，兩半各自的欄重量及整體新欄 Gram 因此保持。對第 $j$ 條新欄，記第一半負號指標的有號改變為 $\delta x_{0,j}$。在 $s_{r,j}=0$ 的位置，第二半有相同改變。在 $s_{r,j}=1$ 的位置，第二半改變反號。這兩類位置各自的 $\delta x_{0,j}$ 總和都是零。若 $H=2P-J$ 是規範化 Paley 方陣，$P$ 是正號指標，則帶配對符號的第一複本投影改變是
$$-8P^{\mathsf T}\bigl(\delta x_{0,j}\,1_{s_j=0}\bigr)$$
而第二複本使用 $s_j=1$。所以所有索引的模八值固定，模十六高位元的改變可由替代遮罩變數的二元線性式直接計算。

## 一個重數等式的不可行證書

上部保留投影中，模十六向量 $(6,4,12,14,14)$ 恰出現三次。相消配對需要下部帶配對符號的保留投影出現同樣三次。生成器對每行的每個可用替代遮罩引入一個布林變數，逐行至多選一個。分組遮罩重數與省略投影精確等式用整數計數器表示。對每個可能出現指定向量的保留欄索引，五個高位元異或式完全決定是否出現。最後只加上指定向量出現三次，其餘向量重數沒有額外條件。

Python 驗算器從實體行重新生成 67,203 個變數及 267,722 條子句，逐一確認證書的 7,356 條前提出自原公式。它在每條推論的否定假設下做單元傳播，核對 587 條反向單元傳播推論。末條是空子句，故所需重數不可能實現。[證書資料](exterior_folded_case8.json.gz)

    python3 -B jobs/hadamard-all-orders/exterior_folded_obstruction.py

搜尋證書時用了 SAT 求解器。上述重跑只需 Python 標準庫。此結果排除的是固定這組行對異或及分組重數的全部重排。第八因數容許改變這些下部特徵的配置仍待判定。

## 放開分組重數後的實體配置

允許改變分組遮罩重數時，只需改動十個實體下部行，就能讓指定向量的重數從四變為三。新配置保持每個行對的異或、逐行重量、兩半各自的欄重量、原 $\beta$、精確新欄 Gram，及每條保留欄索引的模八投影。驗算器直接展開十項替換再取整數內積。這個實例可配對 906 條完整模十六向量，其他新舊內積仍需處理。[十項替換與核對](exterior_folded_obstruction.py)

在同一個 988 上部下，放開分組重數後另有三組實體配置，分別達到 999 組共同模十六配對、996 組共同配對且指定重數為三，以及五個座標各自可全部配對。[更廣的換號見證](EXTERIOR_WIDE_FOLD.md)

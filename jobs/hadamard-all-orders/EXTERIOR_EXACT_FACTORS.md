# 988 上部的八組精確省略投影

固定 [988 配置](EXTERIOR_MOD16_INVARIANT.md) 的上部、兩個來源方陣及原先省略欄。任何精確補法的六條下部非恆定省略欄，其投影矩陣 $\beta$ 取負並除以二後，排列六行只可能得到八個整數矩陣。這個枚舉容許改變下部符號及保留欄配對。[精確枚舉](exterior_exact_factors.cpp) · [輸入重建及輸出核對](exterior_exact_factors.py)

## 枚舉條件

令 $B=-\beta/2$，$G$ 為已固定五欄上部的 Gram 矩陣，$\alpha$ 為兩條非恆定上部省略欄的投影。精確補法要求
$$M=B^{\mathsf T}B=\frac{\alpha^{\mathsf T}\alpha}{4}+599(1200I-G),qquad
B\mathbf1=-599\mathbf1.$$
所以五項欄和 $B^{\mathsf T}\mathbf1$ 可由 $-M\mathbf1/599$ 精確算出。每項 $B_{ij}$ 的絕對值至多 600，因原投影是 1200 項符號的內積。

已有模十六必要條件把六個省略投影低遮罩唯一決定為 $(2,4,7,25,26,28)$。六個遮罩互異，按此順序排列即可固定每項 $B_{ij}\bmod4$。在固定低遮罩下，混合位元式對每條新欄各給四個容許的高遮罩。精確塊的行和及 Gram 隨後可直接驗算。[低遮罩與混合位元條件](EXTERIOR_MOD16_INVARIANT.md)

對一條欄，已知總和、平方和、各項模八值及每項範圍。列出兩組三項，按總和及平方和精確配對，得到全部投影欄候選。Cauchy–Schwarz 界只用來略去剩餘項已無法達到指定總和的前綴。五條欄按候選數由小至大處理，逐一核對兩欄乘積。四條欄一旦選定，第五條由逐行和式唯一決定。

八個矩陣包含已有的下部省略投影。以 $u=(1,-1,0,0,-1,1)^{\mathsf T}$，它們在反射 $B\mapsto B-uu^{\mathsf T}B/2$ 下分成四對。現有條件把任意下部符號的省略投影縮至至多 $8\cdot6!=5760$ 個有標籤的候選。每個候選還須實現為逐行合法的五條下部符號欄，並使全部 1,193 對保留欄投影精確相消。

八個矩陣各有一組精確下部符號行，依六個低遮罩的順序指定實體省略欄。八組都滿足精確行欄平衡、十個新欄間零內積及完整省略欄 Gram，並可配對全部 1,193 個新舊內積向量模八相消。依證書順序，模十六可配對數為 $(882,918,935,891,911,899,912,922)$。仍須選定實體符號行及保留欄配對，讓所有新舊內積精確相消。[八組實體符號行](exterior_exact_factor_witnesses.json) · [整數重現](exterior_exact_factors.py)

## 重跑方式

```sh
c++ -O3 -std=c++20 -Wall -Wextra -Werror \
  jobs/hadamard-all-orders/exterior_exact_factors.cpp -o /tmp/exterior_exact_factors
python3 -B jobs/hadamard-all-orders/exterior_exact_factors.py /tmp/exterior_exact_factors
```

Python 從 988 實體行重建全部枚舉輸入，依序印出八個矩陣，並用獨立整數運算核對每個矩陣的行欄和、混合位元及完整 Gram。

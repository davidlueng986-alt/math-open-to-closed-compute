# 一個 44 維相對跡消去高位移

以 [重新選取首字的峰值 32 見證](BORDER4_2396_PALEY_RESELECTED_HEADS.md) 中原長平方和 119,808 的實體字為來源，其輔助殘差記為 \(E^0\)。令待求實體字的輔助殘差為 \(E\)。保持精確正半部、兩個整數商式及全部模 8，另要求 \(|E_d|<48\)，並在來源的低位移 \(|E_d^0|<24\) 保持 \(|E_d|<24\)。在這些條件下，全部本原模 3 因子，加上一道由 \(\mathbb F_{2^{132}}\) 到 \(\mathbb F_{2^{44}}\) 的相對跡，便足以推出整數 \(E=0\)。此判準沒有其他逐位移模 16 條件。[純 Python 重播](border4_2396_paley_relative_trace_gate.py)

令 \(e=E/8\)。兩個精確整數商式已消去模 3 的真因子分量，所以全部 [本原模 3 因子](BORDER4_2396_PALEY_PEAK32_GATES.md) 歸零會給出 \(3\mid e_d\) 逐係數成立。由全域幅度界，\(e_d\) 只能是 \(0,\pm3\)。非零位移因此恰對應其模二係數為一，而來源所有低位移確定是零。

在特徵二取任一本原 299 次單位根 \(\theta\)。2 模 299 的階為 132，且互反根在另一個 Frobenius 軌道。令 \(m=2^{44}\equiv139\pmod{299}\)，則 \(m^2\equiv185\)，\(m^3\equiv1\)。要求的條件為
\[
 \operatorname{Tr}_{\mathbb F_{2^{132}}/\mathbb F_{2^{44}}}(e(\theta))
 =e(\theta)+e(\theta^m)+e(\theta^{m^2})=0.
\]
這是 44 個二元座標的條件。由 \(e^*=e\)，跡也在互反本原因子歸零。在兩個真因子商群上，各項分別已為零。故 \(e(z)+e(z^m)+e(z^{m^2})\) 整條係數字模二為零。

將非零位移按正負折疊後，倍乘 \(m\) 的每個軌道大小為 1 或 3。上述跡強迫每個軌道的非零位移數為偶數。若某軌道只含一個來源高位移，該位也必歸零。來源 25 個高逆類只餘 \(2,21,71\)。它們在模 13 的逆類各異，分別為 2、5、6。每個整數 \(C_{13}\) 商式的該逆類因此只剩一項，強迫這三項各自為零。這個最後步驟也容許高位移改變符號。

峰值 32 的實體來源已具備商式、模 8 與幅度前提，仍欠本原模 3 與相對跡等式。另一份實體字沿用重新選取首字的第一對，藉由反射區塊的二元線性式與兩組整數邊際計數，取得**完整相對跡為零**。它具有兩個精確整數商式及全部原長模 8，原長模 16 位移數 301，精確位移數 77，峰值 88，平方和 723,456。兩份見證各自達成幅度或相對跡前提。峰值 32 的來源首字被分圓估值排除，後續可重選首字並沿用這份幅度界。[質數 6577 的固定首字排除](BORDER4_2396_PALEY_RESELECTED_HEADS.md)重播直接核查兩份實體資料及全部相對跡係數。

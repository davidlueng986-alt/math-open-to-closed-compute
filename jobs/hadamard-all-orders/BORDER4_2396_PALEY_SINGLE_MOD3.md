# 重選首字後可用單一本原模 3 因子閉合

以[重選首字的第一份峰值 32 見證](BORDER4_2396_PALEY_RESELECTED_HEADS.md)建立逐位區間，來源的輔助殘差為 $E^0$。待求的同一組實體符號須保有兩個精確整數商式和全長模 16，並令其輔助殘差 $E_d$ 位於 0 與 $E_d^0$ 之間，包含兩端點。此時在四個代表本原模 3 因子中匹配**任一個**，即足以得到完整的 2396 階構造。[精確重播](border4_2396_paley_single_mod3.py)

將 $E$ 除以 16。原區間的絕對值不超過 32，因此每個整數位置只允許 0、同號的 1 或同號的 2。它們在模 3 中互異。對任一本原因子，合併兩個商式模 3 和該因子的餘式為零，每組線性核都是 17 維。逐一選取 17 個獨立座標，每個只容許兩值，枚舉全部 $2^{17}=131072$ 組。因子 0、2、3 各只有零解符合全部區間。因子 1 有三組模 3 解符合區間，其中兩組的唯一定界整數提升違反至少一個整數商式，故也只剩零解。

目前用來定義區間的符號已保有兩個精確商式及全長模 8。全長模 16、單一本原模 3 與這組逐位區間仍須由同一組符號同時滿足。另一條搜尋路線只需全長模 8，使用[完整相對跡與本原模 3](BORDER4_2396_PALEY_RELATIVE_TRACE_GATE.md)。

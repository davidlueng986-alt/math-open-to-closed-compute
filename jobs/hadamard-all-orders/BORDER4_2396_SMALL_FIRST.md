# 巢狀四邊框前兩條至多三次換號的完整排除

固定[巢狀支撐](BORDER4_2396_NESTED.md)中商群殘差平方和 256 的正半部
\(S\) 及其精確負半部 \(T\)。每一次換號交換同一條字內一個 \(+1\) 與一個
\(-1\) 的符號。若前兩條合計至多交換三次，且各自序列和仍為 \(0,1\)，
第三、第四條就算容許任意重選符號，只要各自仍為零和、支撐維持互補，
也無法同時達到原長模十六與精確 \(C_{13}\)。
此結論固定 \(T\) 和指定起點，前兩條的交換距離等於相異符號數除以二。

固定互補支撐的四個大小為 \(164,173,130,130\)，依序為偶、奇、偶、偶。
精確 \(C_{13}\) 的相關係數和為 \(553-12\cdot46=1\)，等於四條序列和的平方和。
因此精確候選的序列和必為 \((0,\pm1,0,0)\)。第二條可整體改號以選定 \(+1\)。
上面的交換距離相對於這個規範下的基底計算。

## 如何消去末兩條

先用反射 \(i\mapsto269-i\bmod299\) 對齊末兩條。它們共用 130 點支撐
\(P\)。設 \(A,B\) 為這兩條對齊的字。對任一支撐 \(U\)，令
\[
 L_U(i)_d=[i-d\in U]+[i+d\in U]\pmod2,\qquad 1\le d\le149.
\]
換號造成的自相關變化除以二後取模二，是所翻轉位置的 \(L_U(i)\) 之和。
因此，為了滿足正半部原長模四，只須令前兩條換號的二元向量等於末兩條
相對換號集合的 \(L_P\) 向量。此線性圖的秩為 129，核是整個 \(P\) 的
換號。全域改號 \(B\) 保留自相關與零序列和，所以只需取相對集合的一個代表。

取得新的相對集合後，先在 \(B\) 上實作它，再寫
\(X=(A+B)/2,\ Y=(A-B)/2\)。其他所有選擇都是在對齊後的位置同時翻轉
\(A,B\)，也就是在 \(X,Y\) 各自支撐上換號。末兩條的合併自相關為
\(2(XX^*+YY^*)\)。原長模八可以用 \(L_{\operatorname{supp}X}\)、
\(L_{\operatorname{supp}Y}\) 作二元消去。另加入兩個座標，以要求各組
翻轉數的奇偶符合精確零序列和，即
\(\#F_X\equiv\sum X/2\pmod2\) 及
\(\#F_Y\equiv\sum Y/2\pmod2\)。任一組支撐為奇數時，當下已排除。

## 精確枚舉

兩條共有 14,206 種單次交換。對每條字內的多次交換，把正位置與負位置各自排序
後按順序配對，便把相同的符號改變只算一次。前兩條的模四向量投影到上面秩 129
的像之外，得到 20 個一致性位元。兩次交換查詢相同的一致性向量，
三次交換用前兩個一致性向量的 XOR 查表，再檢查配對順序。

| 交換數 | 通過模四 | 末兩組支撐皆偶 | 通過模八及兩組和的必要奇偶 |
| ---: | ---: | ---: | ---: |
| 0 | 1 | 1 | 1 |
| 1 | 0 | 0 | 0 |
| 2 | 71 | 71 | 0 |
| 3 | 184,238 | 184,238 | 0 |

保留的唯一方案沒有改動前兩條。原相對分組在兩個序列和的奇偶條件加入後，秩為
128，核由 \(X,Y\) 各自整組改號生成，因此所有可能的末兩條合併自相關皆與
原候選相同。原 \(C_{13}\) 殘差在 \(\pm3\) 為 \(-8\)，在 \(\pm4\) 為
\(8\)。因此在固定支撐和規定距離內，同時成立的構造至少要交換四次。

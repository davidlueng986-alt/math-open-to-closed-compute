# 四邊框的 Paley 支撐分解與四元數乘積限制

在 [四行四欄邊框](BORDER4_2396.md) 的 \(C_2\times C_{299}\) 分解中，四條正半部 \(S_i\)
與負半部 \(T_i\) 是三元字。同一條的同一位置恰有一個半部取 \(\pm1\)。完整核心需要
\[
 \sum_i S_iS_i^*=599\cdot1-2J,\qquad
 \sum_i T_iT_i^*=599\cdot1,
\]
其中 \(Q^*\) 將索引取負，\(J\) 是 \(C_{299}\) 的全一群環元素。
這裡給出一族精確正半部，並排除以標準 \(13\times23\) 四元數乘積補齊這一族。

## 將一條完整的 Paley 字分成兩條

用 \(\mathbb F_{599}\) 的非零平方枚舉 \(C_{299}\)。令
\(a(x)=\chi(x-1)\)、\(B(x)=\chi(-x-1)\)，其中 \(\chi\) 為二次字符。
\(a\) 在 \(x=1\) 有唯一零位，其餘位置反對稱。\(B\) 為完整二元字。
在非恆等平方位移 \(r\)，合併自相關是
\(\sum_{x\ne0}\chi((x-1)(rx-1))=-2\)，零位移為 597。兩條的和分別為 0 及 \(\pm1\)。

任取 \(B\) 的循環平移 \(B_k\)。令 \(b_\pm=(B\pm B_k)/2\)。
這兩條支撐恰好分割 \(C_{299}\)，且交叉項抵銷，故
\[
 S=(a,b_+,b_-,0)
\]
仍為精確正半部。相應的負半部須為 \((\pm\delta_0,X,Y,W)\)，其中 \(W\) 是完整二元字，
\(X,Y\) 的支撐分別是 \(b_+,b_-\) 支撐的補集。令 \(U=X+Y\)、\(V=X-Y\)。這給出
\[
 UU^*+VV^*+2WW^*=1196\cdot1,\qquad UV=-B B_k .
\]
第二式是逐位置乘積。反過來，若找到滿足兩式的二元 \(U,V,W\)，以半和、半差還原 \(X,Y\)
便可補齊四邊框。第一式要求一組長度 299 的週期互補四元組有兩條相同的自相關。

在增廣 \(Q(1)=\sum_jQ_j\) 處，\((|W(1)|;|U(1)|,|V(1)|)\) 只有以下四種，
後兩項按大小排序。
\[
 (7;3,33),\quad(11;15,27),\quad(15;11,25),\quad(21;5,17).
\]
這是奇整數等式 \(2W(1)^2+U(1)^2+V(1)^2=1196\) 的全部解。
若從負半部看，單點貢獻一個單位和，其餘三個和按絕對值必為 \((6,11,21)\) 或
\((7,15,18)\)。由於 \(B,B_k\) 的相異位置數為偶數，\(b_+\) 的支撐大小為奇數，
所以偶數和屬於 \(X\)。兩種敘述經 \(U=X+Y,V=X-Y\) 得到相同的四種組合。
若 \(W\) 自身是 \(C_{13}\times C_{23}\) 上的純二元張量，壓縮到兩個商群後，
重複字的零位移貢獻分別是 \(2\cdot13\) 或 \(2\cdot23\) 乘另一因子的和平方。
由 1196 的上界，兩個奇數和按絕對值至多為 5。此時只剩 \(|W(1)|=15\)，因子和大小為 3、5。

## 兩條非重複字不能各自反射對稱

若 \(U,V\) 各有反射中心，可分別平移到中心 0，保持自相關及序列和。
令 \(D_U,D_V,D_W\) 為三條字的負號支撐。由精確互補式除以四得到
\[
 D_UD_U^*+D_VD_V^*+2D_WD_W^*=299\cdot1+(K-299)J ,
\]
其中 \(K=D_U(1)+D_V(1)+2D_W(1)\)。模二下重複項消失，反射對稱給出
\(D_U^2+D_V^2=1+\kappa J\)。因 299 為奇數，指數乘二在二元群環中是自同構，
且固定 \(1,J\)。故 \(D_U+D_V=1+\kappa J\)。
還原二元字後，\(U,V\) 經整條變號至多只在一個位置相異，於是
\(\bigl||U(1)|-|V(1)|\bigr|\le2\)。四種必需的和皆不符合。
這也排除兩條非重複字分別有一條反射對稱字與之共享自相關的情形，
因為可以直接代入這兩條對稱字再用同一證明。

## 四元數乘積的四條輸出自相關皆異

設 \(a,b\) 是 13、23 的任一排序。在 \(C_a\) 取四條合成精確週期 \(T(a)\) 的互斥三元選擇字，
在 \(C_b\) 取四條二元互補字 \(W_j\)，並要求兩兩友好，即
\(W_iW_j^*=W_jW_i^*\)。對稱 Williamson 字滿足這個條件。
在每個座標取四元數乘積，得到四條長度 \(ab\) 的二元字。
固定 \(C_b\) 的傅立葉頻率，四條短字的譜值有共同複相位，
所以右乘短四元數在去掉相位後是按同一比例縮放的實正交變換。由兩個因子的總自相關，
四條輸出的週期自相關合計為 \(4ab\cdot1\)。

若兩條輸出的自相關相同，沿 \(C_a\) 纖維求和後得到的兩條整數字 \(P,Q\)
也有相同自相關。其共同絕對總和 \(R\) 必為上述 \(7,11,15,21\) 之一。
在原始 \(b\) 次單位根 \(\zeta\)，\(P,Q\) 是四條短字的實係數組合，
因此也有共同相位。等模長迫使 \(P(\zeta)=\sigma Q(\zeta)\)，其中 \(\sigma=\pm1\)。
因 \(b\) 是質數，\(P-\sigma Q=kJ_b\) 對某整數 \(k\) 成立。
在 1 取值時，等式左邊為 0 或 \(\pm2R\)。由 \(b\nmid2R\) 得 \(k=0\)。

令 \(\alpha\) 為選擇字的四個和。平方和為 \(a\)，所以絕對值按大小排序在
\(a=13\) 時為 \((0,0,2,3)\) 或 \((1,2,2,2)\)，在 \(a=23\) 時為 \((1,2,3,3)\)。
方程 \(P-\sigma Q=0\) 使短字滿足一個係數關係，其係數是 \(\alpha\) 的四元數乘法
矩陣中兩列的帶符號差。每組交換的係數為 \(u+v,u-v\)（可帶整體符號）。
直接檢查上述三種組合，非零係數有三個、四個，或只有大小為 \(1,5\) 的兩個。

- 兩個大小不等的係數無法使兩個二元符號抵銷。
- 三個係數可先將符號吸收到短字。三個正權重的零和符號分配只有一種互為全反號的分配，
  因為一個權重須等於另外兩個的和。這迫使三條短字成比例。
- 四個正權重若容許含奇數個負號的零和分配，一個權重等於其餘三個的和，
  同樣迫使四條成比例。其餘情形每一列符號的乘積為同一常數。

四條互補的奇長二元字不可能全成比例。長度 23 的四個和只有
\((1,1,3,9)\) 或 \((3,3,5,7)\)，也排除三條成比例。
長度 13 若三條等自相關為 \(C\)，另一條的自相關在非零位移為 \(-3C\)。
取三條的共同絕對和為 1 或 3，另條的絕對和分別為 7 或 5。
第一種時另條至多有三個負號，所有相關至少為 1。但 \(C\) 的非零位移值只能為 \(-3,1\)，
且其和為 \(-12\)，故至少一位為 1。第二種時另條可規範為四個負號，其相關只能為 \(-3,9\)。
負號集合與任何非零平移的交集大小因而為 0 或 3。至少有一個平移交集為 3；
這迫使四點沿該位移構成一條等差數列，兩倍位移的交集大小為 2，矛盾。

最後，友好的短字無法有常數位置乘積。寫 \(W_i=J_b-2D_i\)，其中 \(D_i\) 是負號支撐。
由互補性得到
\(\sum D_iD_i^*=b\cdot1+(K-b)J_b\)，其中 \(K=\sum_iD_i(1)\)。
友好條件給出 \(D_iD_j^*=D_jD_i^*\)。
在特徵二的擴域取一個非平凡 \(b\) 次單位根，令
\(d_i=D_i(\zeta),e_i=D_i(\zeta^{-1})\)，則
\[
 d_i e_j=d_j e_i,\qquad \sum_i d_i e_i=1.
\]
故 \(e=\lambda d\)。若位置乘積為常數，則 \(\sum_iD_i\) 在模二為常數字，
給出 \(\sum_i d_i=0\)，進而 \(\sum_i d_i e_i=\lambda(\sum_i d_i)^2=0\)，矛盾。

兩個因子排序的標準乘積因此都無法提供重複自相關，即使容許獨立平移、變號或反轉輸出。
任意長度 299 的重複自相關互補四元組及其指定支撐仍是存在性問題。

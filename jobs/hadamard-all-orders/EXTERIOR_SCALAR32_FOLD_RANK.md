# 第二欄固定時的折疊秩與支援下界

以[第二座標模三十二完全相消的十組欄對配置](EXTERIOR_SCALAR32.md)為參考，保留 988 上部和全部 1,200 個下部第二欄實體符號。要讓 1,193 組五維相消都達到模十六，其餘四欄的物理折疊變化必須各自非零，且任兩欄的變化不能相同。若每個實體行重量的奇偶也維持，四個變化遮罩的二元秩必須恰為三。

再保留全部 35 項精確省略投影和原先十組指定精確五維欄對，則至少要有 **十個不同的物理基底行對**發生折疊變化。此下界容許任意重配其餘舊欄、任意改動兩半各欄的重量和新欄 Gram。[整數驗算](exterior_scalar32_fold_rank.py)

## 第二座標分組的配對限制

記某新欄在兩個半部的負號位元為 $a_r,b_r$，折疊為 $a_r\oplus b_r$。比較新舊實體配置，令 $d_r$ 為折疊變化，$\Delta W_0,\Delta W_1$ 為兩半負號數之差。記 $h_{ri}\in\{1,-1\}$ 為正規化 Paley 舊欄符號。第 $s$ 個 Sylvester 複本的帶配對符號投影變動滿足
$$\Delta\lambda_{i,s}\equiv-2(\Delta W_0+(-1)^s\Delta W_1)+4\sum_{h_{ri}=-1}d_r\pmod 8.$$
同一新欄的上部投影全在固定模四類。若完整模十六配對成立，下部投影必須仍落在這個類。因此兩個括號中的重量差為偶數，且 $d$ 的重量為偶數。於是折疊變化對每個舊欄投影的模八高位，給出一個 Paley 二元線性作用，每個複本另可有一個獨立常數位元。

每項五維模十六相消都必須保存第二欄模十六值，以及所選其他欄模八高位的 XOR。若單一折疊維持，或兩個折疊的變化完全相同，對應的 XOR 只可能在各複本整體翻轉。枚舉這四種兩複本翻轉後，可相消數的上界如下。

| 所取欄集合 | 條件投影相消上界 |
| --- | ---: |
| 1 | 1,165 |
| 3 | 1,173 |
| 4 | 1,170 |
| 5 | 1,186 |
| 1、3 | 1,164 |
| 1、4 | 1,185 |
| 1、5 | 1,177 |
| 3、4 | 1,177 |
| 3、5 | 1,185 |
| 4、5 | 1,164 |

每個基底行對的五條折疊位元之 XOR 由兩個實體行重量的奇偶決定。第二欄固定且行重量奇偶保持時，其他四條的變化 XOR 為零。上表排除單一變化為零或任兩條相同，故也排除三條的 XOR 為零。四個變化因此生成秩三，七個非零線性組合可用四條個別變化及三條互補的兩欄 XOR 代表。[逐欄條件多重集](exterior_scalar32_fold_rank.py)

## 匹配精確指定欄的短支援枚舉

若省略投影及十組欄對都精確保持，對應的 27 個下部舊欄模八高位也固定。在每個 Sylvester 複本內，變化遮罩的 Paley 像必須在這些固定索引取相同位元值。選取各複本的一個固定索引，便能消去兩個常數位元，得到一組二元齊次條件。該條件同時適用於四條個別變化和三條兩欄 XOR。

逐一枚舉兩行的 Paley 限制簽名。相等的簽名只給出兩個重量二的支援 $(124,145)$ 和 $(190,515)$。對七個條件投影而言，兩者的最佳相消數皆小於 1,193。因每個變化重量為偶數，生成空間的七個非零字重量均至少為四。若所有變化合併後只有 $m$ 個位置，每個位置恰在七個非零字中的四個出現，故七個重量之和為 $4m$。

若 $m\leq9$，至少有三個重量四的非零字。把四個位置分成按索引排序的前兩個及後兩個，兩對的簽名 XOR 必須相等，可以完整枚舉出 80,933 個符合齊次條件的重量四支援。再逐一核對第二座標分組的條件投影，七個角色依序留下 5、237、8、679、53、5、281 個支援。枚舉排除任何可行的相依三元組，因此現有的至少三個重量四非零字必能選成一組基底。以所有此類基底重建七個非零字後，合併支援至多九的位置共有 2,775 個候選，全部至少違反一項條件投影。這給出十個不同基底行對的下界。[短支援與線性組合重跑](exterior_scalar32_fold_rank.py)

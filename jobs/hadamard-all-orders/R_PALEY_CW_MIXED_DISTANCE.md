# Cooper–Wallis 來源上的遠距與九翻轉混合內部欄

用既有的 Cooper–Wallis 1196 階 Hadamard 來源。第一條內部向量取既有週期遠距對的第一條，最近帶符號來源欄距離為 503。第二條從實體來源欄 277 取出，在原始行

$$
0,\ 23,\ 46,\ 92,\ 184,\ 207,\ 230,\ 253,\ 276
$$

翻轉，距最近帶符號來源欄恰為 9。這九個位置位於同一個模 23 相位。所有實體索引從零開始。

設 $p_z(c)=\langle z,H_c\rangle/2$。兩條原始向量的內積為 16。兩組半投影絕對值均為 1 的共同座標有 616 個，其中 296 個同號、320 個異號。選取 296 個同號和 304 個異號，使

$$
2(296-304)+16=0.
$$

所得 $2396\times1202$ 部分矩陣的 721,801 組欄內積均為零。保留向量在 $\mathbb F_{599}$ 上秩為 2。矩陣 SHA256 為 `8ae60bc91e90b7f58a6bf19ccb15aa5f981c9002141979f20466003f5d952ff3`。

這是一個兩種距離共用同一組外部索引的實體見證。可用同一來源的 23 階循環自同構平移兩條內部向量與外部索引，得到整個相容軌道。

## 同一外部索引上的五條單翻轉欄

保留同一組 600 個外部索引，依序加入下列實體 `(原始行, 保留欄)` 的單翻轉向量。

| 原始行 | 保留欄 |
| ---: | ---: |
| 856 | 987 |
| 720 | 475 |
| 244 | 674 |
| 236 | 160 |
| 9 | 1180 |

所得矩陣為 $2396\times1207$，七條新增向量的最近帶符號來源距離依次為 $503,9,1,1,1,1,1$。全部 727,821 組欄內積均為零，保留向量在 $\mathbb F_{599}$ 上秩為 7。矩陣 SHA256 為 `1dd6f6a24b341ce68b6bdc2f86f7de0feb5b3d4eb4484f0e3da7a090c1f82ae4`。

在作業目錄執行 `python r_paley_cw_mixed_distance.py` 可逐對重播所有欄內積。
